WaterWise Advisor is a web application where users enter their household size, residence type, water-using activities (from a predefined list or custom-entered), and whether they have noticed leaks or high bills. The system uses an AI logic layer — designed and structured using IBM Bob — to process the inputs and generate a fully personalised response comprising:

High water-use activity identification specific to the user's context
Curated water-saving tips mapped to each selected activity
Residence-type-specific advice (apartment, hostel, villa, farmhouse, etc.)
Leak and high-bill alerts with actionable diagnostics
A structured 7-day action plan with daily goals
